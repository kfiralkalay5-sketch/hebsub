# hebsub – תרגום כתוביות מאנגלית לעברית, מקומית על המחשב

hebsub מתרגם כתוביות באנגלית של סרטים וסדרות לכתוביות בעברית. התרגום רץ על המחשב שלכם, עם מודל שפה מקומי דרך [Ollama](https://ollama.com), בלי לשלם על שירות ענן.

## מה יש בתרגום
- **זכר ונקבה:**
  - רשימת דמויות לכל פרק, ופנייה בזכר או בנקבה לפי מי מדבר ואל מי.
  - מעבר נוסף שבודק את הצורות האלה.
- **ניקוי של כתוביות המקור:**
  - תיאורי צלילים ושמות דוברים, כמו `[sighs]` ו-`[Name]`.
  - קרדיטים של קבוצות תרגום.
  - תיאורי מוזיקה.
- **עקביות:**
  - שמות ומונחים כתובים אותו דבר לאורך כל הסדרה.
  - זיכרון דמויות לכל סדרה.
- **בדיקה ועריכה:**
  - בדיקה של כל המשפטים מול האנגלית.
  - תיקון של שורות קטועות ושל מילים באנגלית שנשארו.
- **פורמט:** פלט SRT עם כיווניות מימין לשמאל, ובדיוק אותם זמנים כמו באנגלית.

איכות: התרגום מובן וזורם, אבל עדיין לא ברמה של מתרגם מקצועי. בבדיקות עיוורות מצאו בו בערך פי 2 עד 3 יותר טעויות מאשר בתרגום אנושי.

## דרישות
| רכיב | מינימום |
|---|---|
| מערכת הפעלה | Windows 10/11, macOS (Apple Silicon), Linux |
| Python | 3.10 ומעלה |
| זיכרון למודל המומלץ (Gemma 4 26B) | כרטיס מסך עם 20GB לפחות (למשל RTX 3090/4090), או מק עם 32GB זיכרון |
| מחשב חלש יותר | אפשר מודל קטן יותר (ראו למטה), באיכות נמוכה יותר |
| ffmpeg | נדרש כדי לחלץ כתוביות באנגלית מתוך קובץ הווידאו |

## התקנה

### Windows (PowerShell)
```powershell
winget install Ollama.Ollama
winget install Python.Python.3.12
winget install Gyan.FFmpeg
# פתחו PowerShell חדש אחרי ההתקנות
ollama pull hf.co/unsloth/gemma-4-26B-A4B-it-GGUF:UD-Q4_K_M
git clone <כתובת המאגר> hebsub
cd hebsub
python -m pip install -e .
hebsub check
```

### macOS
```bash
brew install ollama ffmpeg python@3.12
ollama pull hf.co/unsloth/gemma-4-26B-A4B-it-GGUF:UD-Q4_K_M
git clone <כתובת המאגר> hebsub && cd hebsub
python3 -m pip install -e .
hebsub check
```

### Linux
```bash
curl -fsSL https://ollama.com/install.sh | sh
sudo apt install ffmpeg python3-pip   # או המקבילה בהפצה שלכם
ollama pull hf.co/unsloth/gemma-4-26B-A4B-it-GGUF:UD-Q4_K_M
git clone <כתובת המאגר> hebsub && cd hebsub
python3 -m pip install -e .
hebsub check
```

## שימוש
```bash
hebsub translate "D:\TV\Show\Season 1\Show.S01E01.mkv"     # פרק אחד
hebsub scan "D:\TV\Show" --translate                       # כל מה שאין לו עברית בתיקייה
hebsub check                                               # בדיקת התקנה וחיבור למודל
```
- **מאיפה מגיעות הכתוביות באנגלית:** המתרגם מחפש קובץ באנגלית ליד הווידאו, למשל `Show.S01E01.en.srt`. אם אין כזה, הוא מחלץ את הכתוביות מתוך הווידאו עם ffmpeg.
- **מה נוצר:** קובץ `Show.S01E01.he.srt` ליד הווידאו.
- **כתוביות קיימות:** הן לא נדרסות. אם כבר יש כתוביות בעברית, הפרק מדולג (אלא אם מוסיפים `--force`).

## הגדרות
- **בלי הגדרות בכלל:** הכלי עובד עם ברירות המחדל שב-`hebsub/default_config.json`.
- **כדי לשנות:** מעתיקים את `config.example.json` ל-`config.json` בתיקיית הנתונים ועורכים אותו. אפשר גם להעביר נתיב עם `--config`.
- **איפה תיקיית הנתונים:**
  - Windows: `%APPDATA%\hebsub`
  - macOS: `~/Library/Application Support/hebsub`
  - Linux: `~/.local/share/hebsub`
  - אפשר לשנות אותה עם משתנה הסביבה `HEBSUB_HOME`.
- **מודל קטן יותר:** משנים את `ollama.model`, למשל ל-`gemma3:12b`. צריך כ-10GB, והאיכות נמוכה יותר.
- **מפתחות API:** לא נשמרים בקובץ ההגדרות. שמים אותם במשתני סביבה. ב-Windows: `setx TMDB_API_KEY "..."`, ובמק ובלינוקס: `export ...`.

## הגדרה מודרכת: `hebsub setup`
מריצים פעם אחת בטרמינל או ב-PowerShell:
```bash
hebsub setup
```
האשף:
- בודק ש-Ollama רץ ושהמודל מותקן. אם לא, הוא מציע להוריד אותו.
- מוצא את ffmpeg.
- מחבר אופציונלית:
  - **TMDB:** מפתח חינמי מ-themoviedb.org, שאומר איזו דמות גבר ואיזו אישה, וזה משפר מאוד את הזכר והנקבה בעברית.
  - **Sonarr ו-Radarr:** להורדות חדשות ולמציאת הספרייה. האשף שואל איפה כל תיקייה שלהם נמצאת במחשב הזה, למשל `/tv` מתוך Docker מול `D:\TV` או `\\NAS\TV`.
  - **Bazarr:** כדי להוריד כתוביות באנגלית כשאין לסרטון.

כל חיבור נבדק מיד. המפתחות נשמרים בקובץ `secrets.json` בתיקיית הנתונים, ולא בקובץ ההגדרות.

## תרגום אוטומטי ברקע: `hebsub watch`
```bash
hebsub watch                      # עם התיקיות של Sonarr/Radarr
hebsub watch "D:\Movies" "D:\TV"  # או תיקיות מסוימות
```
- **סדר העבודה:** הורדות חדשות מתורגמות ראשונות. כשאין חדשות, הוא ממשיך לתרגם את כל מה שאין לו עברית בספרייה, כותר אחרי כותר.
- **כשאין כתוביות באנגלית:** הוא מנסה שוב כל 6 שעות, במשך שבוע.
- **אחרי הפעלה מחדש:** הוא ממשיך מאיפה שעצר.

**הפעלה אוטומטית עם המחשב:**
- **Windows (PowerShell):**
  ```powershell
  schtasks /Create /TN hebsub /SC ONLOGON /TR "hebsub watch" /RL LIMITED
  ```
- **macOS:** קובץ launchd ב-`~/Library/LaunchAgents/hebsub.plist`, עם `ProgramArguments` = הנתיב ל-`hebsub` ואחריו `watch`, ו-`RunAtLoad` = true. אחר כך מריצים `launchctl load ~/Library/LaunchAgents/hebsub.plist`.
- **Linux (systemd, משתמש):** יוצרים את הקובץ `~/.config/systemd/user/hebsub.service` עם התוכן:
  ```ini
  [Service]
  ExecStart=%h/.local/bin/hebsub watch
  Restart=on-failure
  [Install]
  WantedBy=default.target
  ```
  ואחר כך מפעילים:
  ```bash
  systemctl --user enable --now hebsub
  ```

## רכיבי קול (אופציונלי): זכר ונקבה טובים יותר
```bash
pip install -e ".[voice]"
hebsub setup
```
בשלב 6 של `hebsub setup` מתקינים את שני רכיבי הקול. שניהם רצים על המעבד בכל מערכת הפעלה, ולא צריך כרטיס מסך.

**זיהוי הדובר מהקול:**
- **מה הוא עושה:** בודק בכל שורה אם מדבר גבר או אישה, ואם פונים לגבר או לאישה.
- **ההתקנה:** האשף מוריד אוטומטית מודל של 26MB מ-sherpa-onnx.

**מסווג "אל מי פונים":**
- **מה הוא עושה:** קובע אם ה-"you" באנגלית הוא "אתה" או "את".
- **ההתקנה:** הקובץ `addressee-model.zip` (90MB) מצורף לעמוד ה-Releases של המאגר. האשף מבקש את הכתובת שלו.
- **למי שמנהל את המאגר:** מעלים את הקובץ כ-Release asset.

## למידה עצמית: `hebsub learn`
```bash
hebsub learn                  # עם התיקיות של Sonarr/Radarr
hebsub learn "D:\TV"          # או תיקיות מסוימות
```
`hebsub watch` מריץ את הלמידה לבד כל 6 שעות. כל מה שנלמד נשמר בתיקיית הנתונים ולא נשלח לשום מקום.

**מהספרייה שלכם:**
- **אוצר מילים:** כל קובץ כתוביות עבריות של מתרגם אנושי שנמצא ליד סרטון נכנס לאוצר המילים. בודק האיות משתמש בו כדי לזהות מילים שגויות או מומצאות בתרגום.
- **שמות ומונחים של כל סדרה:** כשיש לסרטון גם כתוביות באנגלית וגם עבריות אנושיות, השורות מוצמדות זו לזו לפי הזמנים. זה עובד גם כשהכתוביות מוזזות בכמה שניות או מגרסה עם קצב פריימים אחר. מהזוגות האלה נלמד איך המתרגמים של הסדרה כותבים שמות ומונחים, והפרקים הבאים משתמשים באותו כתיב.
- **מה לא נלמד:** כתוביות ש-hebsub עצמו כתב לא נכנסות ללמידה אף פעם.

**מהתיקונים שלכם:**
- hebsub שומר עותק של כל קובץ שהוא כותב. אם תתקנו את קובץ ה-`.he.srt` ליד הסרטון בכל עורך כתוביות, הלמידה הבאה תמצא את השורות שתיקנתם.
- מילה או שם שתיקנתם באותה צורה לפחות פעמיים בסדרה, למשל כתיב של שם, הופכים לכלל. הכלל חל על כל פרק עתידי של אותה סדרה, וגם על טבלת השמות שהמתרגם מקבל.
- תיקוני זכר ונקבה (אתה/את, יודע/יודעת) לא הופכים לכלל של מילים, כי הם תלויים במי מדבר ואל מי.
- **זכר ונקבה של דמות:** אם תיקנתם לפחות פעמיים את הפנייה לאותה דמות בשורות שבהן פונים אליה בשמה, למשל "אתה יודע, מנדי" ל-"את יודעת, מנדי", המין שלה נקבע בזיכרון הדמויות של הסדרה. מעכשיו כל פרק חדש מתחיל ממנו. דמות שנעלתם ידנית בזיכרון (`"locked": true`) לא משתנה.
- כל התיקונים נשמרים ב-`learn/corrections.jsonl` והכללים ב-`learn/user_terms.json`, בתיקיית הנתונים. אפשר לערוך או למחוק אותם.

- **אימון המודל (אופציונלי, כבוי כברירת מחדל):** כוונון LoRA על הכתוביות האנושיות שבספרייה, למחשבים עם Apple Silicon או NVIDIA.

## רישיונות
- **CueIvrit:** הכלים בתיקייה `hebsub/vendor/cueivrit` (הכנה, בנייה ובדיקה של קבצי SRT) הם CueIvrit מאת Guy Tsarfati, ברישיון MIT. הרישיון המלא נמצא בתיקייה.
- **המודלים:** יש להם רישיונות משלהם. Gemma מופץ בתנאי השימוש של Google.
